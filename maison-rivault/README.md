# Maison Rivault website

A static, mobile-first site for Drop 001 (opens November 23, 2026). Source is plain HTML, CSS and a little JavaScript, generated by a small Python script. No frameworks, no build dependencies.

## Run it

```
python3 build.py                        # writes ./site
python3 -m http.server -d site 8000     # preview at http://localhost:8000
python3 tools/check_placeholders.py     # lists everything still to replace
```

`site/` is committed so you can host it as-is on any static host. Re-run `build.py` after editing `site.config.json`, `data/products.json` or anything in `src/`.

## Where things live

| What | Where |
| --- | --- |
| Prices, colors, sizes, fiber, fit, care, photos, bundles | `data/products.json` |
| Domain, Instagram, contact email, shipping, returns, email provider, analytics | `site.config.json` |
| Design tokens (colors, type, spacing) | CSS variables at the top of `src/assets/css/main.css` |
| Page copy and layout | `build.py` (one function per page) |
| Cart, signup, consent, filters | `src/assets/js/site.js` |
| Logo files | `src/assets/img/logo/` (`lockup.svg` and `monogram.svg` are cropped from the master; `favicon.svg` is the monogram in green) |

## How the pieces behave

- **Before the launch date** every product shows "Join the waitlist" instead of "Add to cart", and the announcement bar shows the date. On and after November 23, 2026 (Arizona time) the same pages switch to Add to cart and the bar hides. To test early, set `commerce.force_open` to `true`.
- **Any empty config value or missing product detail** renders as a visible orange `[confirm: ...]` marker. Nothing is invented. `tools/check_placeholders.py` counts them and exits non-zero while any remain, so it can gate a deploy.
- **Photos:** every image slot is a flat cream placeholder with a caption. Swap one by setting `"src": "assets/img/photos/quarter-zip-front.jpg"` on that image in `products.json`. Put the files in `src/assets/img/photos/`.
- **Pricing:** one real price per item, no was-prices, no timers, no stock banners. Bundle savings are calculated from the component prices, so they stay correct when you change a price.
- **Email signup** posts to Klaviyo (set `email.provider` to `klaviyo`, plus the public key and list id) or to a generic JSON endpoint. If neither is set the form says signup is not connected. It never shows a thank-you unless the request succeeded. The Klaviyo call follows their client subscription API but has not been tested against a live account.
- **Analytics** (GA4, Meta Pixel) load only after a visitor accepts the cookie banner. The default is decline.
- **Cart and checkout:** the cart is stored in the browser. Checkout builds a Shopify cart link from `commerce.shopify_domain` and each item's `shopify_variant_ids` (keyed by size, for example `{"M": "1234567890"}`). It stays disabled until those are filled in. Bundles need their own Shopify variants, keyed by the sizes in item order, joined with `|`. Set that up in Shopify before launch, or the bundle line cannot check out.

## Before launch

See `PLACEHOLDERS.md`. In short: supplier prices, product photos (Nov 9 to 22), fiber content and care text (US labelling rules, have a lawyer confirm), shipping and returns terms, domain, Instagram handle, contact email, location, Shopify and email provider hookup, and a legal read of Privacy and Terms.

The logo files were traced from an AI-generated image. They are fine on screen. Have a designer redraw clean vectors before any print or embroidery.
